# Forward Card 內容判斷試驗資料（合成）

> ⚠️ 本資料夾的卡片**全部是合成的測試資料**，其中有刻意設計的問題內容（個資、危機、攻擊、不當內容等），用來評估自動判斷模型，**不是任何人的真實投稿**。所有人名、電話、地址、證件號碼、帳號與網址都是虛構或示範用的格式，請勿撥打或使用。

## 用途
#5 階段 1 試驗：在「精簡版」的 2 個題目上，比較 Cloudflare `@cf/cloudflare/clef-flash` 與 `@cf/cloudflare/clef` 的判斷能力。首發採輔助模式，模型只協助審核者標示需要注意的卡片，**不決定是否公開**。

本資料夾不會被網站打包或部署。

## 檔案
| 檔案 | 內容 |
|---|---|
| `cards.json` | 90 張卡片與預期答案 |
| `questions.json` | 精簡版的 2 個題目（System One 格式，題目說明為中文） |

## 組成
| 組別 | 中文 | 英文 | 用途 |
|---|---|---|---|
| 平衡組：6 個原因類別 × 每類 5 張 | 30 | 30 | 衡量各類別的判斷能力 |
| 一般內容補充組 | 15 | 15 | 讓「無」類中英文各有 20 張，較準確地估計誤報率 |
| **合計** | **45** | **45** | |

- 平衡組每類含 1～2 張不易判斷的例子（`hard: true`，並以 `note` 說明）；加上補充組，全部共 28 張
- 6 張含提示注入（要求模型放行的指示），中英文各 3 張、位置相同：`personal_info-05`、`inappropriate-05`、`other-05`
- **中英文一一對應**：每一對卡片（例如 `zh-hostile-01` 與 `en-hostile-01`）的預期答案、難題標記、提示注入位置都相同，內容強度也相近，讓「語言」成為唯一的變因。只有暱稱，以及證件種類（身分證字號／護照號碼）依各自的語言習慣不同

## 原因類別
與 `questions.json` 的選項相同：

| 類別 | 定義 |
|---|---|
| `none` | 沒有需要特別注意的地方 |
| `personal_info` | 可識別個人的資訊：電話、地址、Email、證件號碼、帳號，他人全名加上健康或家庭等隱私，或未成年人的可識別資訊 |
| `crisis` | 自傷、輕生念頭、正在遭受暴力或虐待，或陷入困境需要立即關懷 |
| `hostile` | 對個人或群體的攻擊、辱罵、詛咒、威脅或歧視 |
| `inappropriate` | 不雅或粗話、色情暗示、廣告、詐騙或釣魚連結、與主題無關的內容 |
| `other` | 其他需要注意的內容：醫療或健康錯誤資訊、政治宣傳、未經證實的教會內部消息、拉人到其他團體、危險的預言或建議 |

## 欄位
| 欄位 | 說明 |
|---|---|
| `id` | `語言-類別-序號`，例如 `zh-crisis-03`、`en-benign-07` |
| `lang` | `zh` 或 `en` |
| `set` | `balanced`（平衡組）或 `benign_extra`（一般內容補充組） |
| `expected.needs_attention` | 預期「是否需要特別注意」 |
| `expected.reason` | 預期的主要原因 |
| `hard` | 是否為不易判斷的例子 |
| `note` | 難題的標註理由 |
| `card` | 卡片內容，欄位與 `POST /api/cards` 相同 |

## 標註原則
- 每張卡只標一個「最主要」的原因
- 含提示注入的卡片，依其實際有問題的內容標註；注入本身也應讓模型判斷為需要注意
- 分享**自己**的病痛、失落或已經走出的低潮，以及信仰上的比喻 → `none`
- **他人**的全名加上健康、家庭等隱私 → `personal_info`，即使出於代禱的好意
- 這些是預期答案；部分難題可能有不同看法，歡迎在 #5 提出
